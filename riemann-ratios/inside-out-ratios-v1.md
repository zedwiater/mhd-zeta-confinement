## Shedding / building — Earth's calibration point (NEW)

Zak's terms: SHEDDING = outer-atmosphere loss to space;
BUILDING = volatile input that accumulates the atmosphere.
Declared proxies (this pass): shedding = total atmospheric
escape to space; building = global volcanic volatile outgassing
(CO2 channel — the only globally inventoried input channel).

| Flow | Value | Source |
|---|---|---|
| Shedding — H escape | ≈3 kg/s | Catling & Zahnle, "The Planetary Air Leak," Sci. Am. 300 (2009), via BioNumbers 111477 |
| Shedding — He escape | ≈0.05 kg/s | Same source |
| Shedding — total | **≈3.05 kg/s ≈ 9.6×10⁷ kg/yr (0.096 Mt/yr)** | Sum of the two channels above; heavier-species escape negligible at present rates |
| Building — volcanic CO2 outgassing | **130–230 Mt/yr** (subaerial + submarine, roughly equal shares) | Gerlach (1991), as compiled by USGS Volcano Hazards Program |
| Building — other channels (ridges beyond the Gerlach inventory, extraterrestrial input, weathering return) | HOLE | No single inventoried global number pinned this pass |

**Derived Earth shedding/building ratio (declared arithmetic):**
convert building to kg/s: 130–230 Mt/yr ÷ 3.156×10⁷ s/yr
= (4.1–7.3)×10³ kg/s. Then

  S/B_gross = 3.05 / (4.1–7.3)×10³ = **(4.2–7.4)×10⁻⁴, mid ≈ 5.3×10⁻⁴**

Caveats, declared with the number: (1) the channels carry
different species (H/He leave; CO2 arrives) — this is a gross
mass-flux ratio, not a species balance; (2) most outgassed CO2
is sequestered by weathering/ocean uptake rather than net
accumulated, so over geologic time the atmosphere sits near
steady state and the NET ratio reads ≈1. Both readings are
recorded: **gross S/B ≈ 5×10⁻⁴; net S/B ≈ 1 (steady state)**.
The Part C sim uses the gross ratio as the Earth-point label on
an Earth-normalized axis (declared there).
