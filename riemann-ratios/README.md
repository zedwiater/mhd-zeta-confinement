# Riemann Ratios — the range atlas (rounds 1–4, 2026-11-16 → 11-18)

A subdirectory of the zeta program. In the parent catalog's flow
table (../SYSTEM_CATALOG.md), the universe's traffic splits into
two columns: **power** (energy, NS-routed) and **data** (pattern,
Riemann-accounted). This directory is where the data column gets

## What the tables are for

The tables are a **range atlas**: ratios as addresses, so that
for any band — a frequency range, a calm range, a thermal delta —
we can say *which daughters live in it*, at every tier, in one
language. (Program author, 2026-11-18: "we want these ratios so
we can know what light solidic daughters live in what range.")
The current work is general layout — reconnaissance for target
zones. Most of the real work will be in the subspectra and
hyperspectra the layout points to.

**The job** (author, 2026-11-16): "every stable tripole of the
parents that form sub container reveal finer ratios eventually
revealing the ideal containment geometry of waves." Tables expose
parents, reveal daughters capable of being symbiotic parents with
unique children, and profile each symbiotic system: the core
logic it makes, and the phases it gains and sheds.

**Falsifiability** (author, 2026-11-18): a parent tier cannot
obscure its nature, because its nature is what its daughters are
made of. If a claimed parent leaves no consistent signature
across its daughters, the claim dies. Language itself is treated
as a symbiotic parent on the same terms: its daughters error-
correct, and persist in uniqueness and root/core logic.
